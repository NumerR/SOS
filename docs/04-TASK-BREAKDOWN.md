### T0.2 Закрыть дыры аутентификации (Агент 2) — выполнено, закоммичено в двух коммитах (`f1b4c7e`, `1485482`)

6/15 мин по IP), ключ лимитера из `X-Forwarded-For` за явным `TRUST_PROXY=true`
(`ClientIP`), `X-Forwarded-Proto` больше не доверяет заголовку без того же

Тесты: `internal/ratelimit/limiter_test.go` (8), `internal/handlers/auth_test.go`

### T0.3 Привести HTTP-сервер в production-вид (Агент 2)

- `http.Server` с `ReadTimeout`, `WriteTimeout`, `IdleTimeout`, `MaxHeaderBytes`; graceful shutdown по `SIGINT/SIGTERM` с `Shutdown(ctx)` (`main.go:137` — сейчас `ListenAndServe` без таймаутов и без остановки).
- `context.WithTimeout` на все обращения к БД (сейчас 0 в `internal/`).
- `slog` JSON-логгинг + request id; логирование 4xx/5xx без тела запроса.
- Cookie `__Host-` префикс при TLS (доверие `X-Forwarded-Proto` уже закрыто в T0.2 через `TRUST_PROXY`).
- Лимиты длин полей в заданиях/сдачах/оценках (длина пароля ограничена в T0.2).
- Приёмка: `kill -TERM` → сервер доливеает активные запросы и выходит 0; `curl` на `/api/health` даёт `{"status":"ok","db":"ok"}` (проверка `db.PingContext` с таймаутом).
